# VRMC 1.4.0

Feedback on 1.3.8: the game is muted after reopening the headset, the bow does not line up with the
crosshair, and the shortcut (radial) menu shows two cursors. New: a simple hand model with arm, hand
and fingers that shows what the gesture engine sees, and a mod browser for Modrinth and CurseForge.

Status: host build and provider tests PASS, signed build installed on D1. **Not yet checked on the
headset** (VERIFY.md EV-0305).

## Fixes

- **Sound after reopening the headset.** Taking the headset off suspends the app; the audio session
  comes back but Minecraft's OpenAL device stays silent. The launcher now re-activates the audio
  session and asks the game to restart its sound engine when the app returns from the background or
  the system ends/recommends resuming after an audio interruption (`audio-reset` game command). The game
  also restarts the sound engine by itself after a frame-loop stall of more than 3 s, as a backstop.
  Restarts are at most one per 5 s.
- **Bow lines up with the crosshair.** While drawing, the bow hand's pose is turned to the aim
  direction the arrow will fly along, so the bow, the arrow and the crosshair agree.
- **One cursor in the shortcut menu.** The radial menu's cursor now follows your head (the same
  head-ray as other menus). The second, hand-driven cursor is hidden. Selecting works as before:
  hold the right fist, look at an option, open the hand.

## New

- **Hand model.** A simple blocky arm (forearm and sleeve), palm, thumb and four fingers built from the
  hand-tracking joints, so every finger moves like yours. Colours show what the game reads:
  - cyan as the index finger and thumb approach a pinch, green while the pinch is held
  - orange on the right hand while breaking
  - amber for a left fist; purple filling while a right fist opens the shortcut menu
  - yellow while the middle-finger pinch is held
  The model is lit by the light level where you stand. While drawing the bow the draw hand is hidden
  so it never blocks the aim. To go back to Vivecraft's arms, add `hands.model=vivecraft` to the tune
  file.
- **Mods tab** in the launcher:
  - Browse Fabric mods for Minecraft 26.2 on **Modrinth** (no account needed) or **CurseForge** (needs
    your own free API key from console.curseforge.com, stored in this headset's Keychain and sent only
    to api.curseforge.com).
  - Search, sort by relevance/downloads/updated, details page, open on the website.
  - Install the latest compatible build plus its required mods. Every file is checked against the hash
    the site publishes (SHA-512 on Modrinth, SHA-1 on CurseForge) and must be a Fabric mod before it is
    moved into the mods folder.
  - Rendering mods that are known to clash with Vivecraft (Sodium, Iris, Distant Horizons, ...) are
    marked "May not work in VR" and ask before installing.
  - Installed list: turn mods on/off, remove, check for updates (Modrinth recognises jars by hash,
    including ones you added yourself), import a .jar from Files. VRMC provider, Vivecraft and Fabric
    API are locked.
  - Changes load the next time the game starts.

## Please check on the headset

1. Play, take the headset off for a minute, put it back on: sound should come back within ~2 s.
2. Draw the bow: the bow points at the crosshair and arrows land on it.
3. Hold the right fist: the shortcut menu has one cursor that follows your head.
4. Hands: arm, palm and fingers follow yours; pinch turns cyan then green; breaking turns orange.
5. Mods tab: search Modrinth, install a small mod (e.g. a HUD or minimap mod), restart the game.

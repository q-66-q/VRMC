# VRMC source offer (GPLv3 / LGPLv3 compliance)

This package ships only VRMC's own native app, the VRMC provider jar, documentation, and licensing
notices. It does **not** include Minecraft, Vivecraft, or any Mojang/Microsoft assets.

## Corresponding source

VRMC is built from the source tree this file belongs to. The exact source commit and component versions
for a release are recorded in the release manifest generated by `scripts/m6_release_manifest.sh`
(`source_commit`, `source_branch`, `versions.env` pins, app/bridge/provider hashes).

- App + launcher + compositor: GPLv3 (see `LICENSE`).
- VRMC provider: LGPLv3 (see `provider/LICENSE`); its corresponding source is under `provider/src/`.
- Bridge / native shared ABI: `bridge/`, sources included in the tree.
- Third-party components and their licenses: `THIRD_PARTY_NOTICES.md`.

For any binary distribution, the corresponding source for the exact release is available from the same
distribution channel as the binary, or on written request to the project maintainer for at least three
years from the distribution date. The source may also be obtained from the project's public repository
at the commit recorded in the release manifest.

## Rebuilding

- Host: `scripts/build_shell.sh`, `scripts/build_launcher.sh`, `scripts/build_provider.sh`,
  `scripts/stage_native_app.sh`; tests under `provider/tests/run_tests.sh` and `bridge/tests/run_tests.sh`.
- Device: see `docs/mvp/DEVICE_STACK.md`, `README.md`, and `M5_DEVICE_RUN.md`.
- The provider jar is a replaceable LGPL component; keep it separately replaceable by users.

## No Minecraft redistribution

VRMC requires a user-owned Minecraft Java installation and a compatible Vivecraft distribution. Those
are not bundled, linked as a combined work, or redistributed by this package. Users must obtain them
under their own licenses.

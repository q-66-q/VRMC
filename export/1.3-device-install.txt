## What this build is
Single native visionOS window UI: Play, Comfort, Controls, Help. Pressing Play starts Minecraft in
place through a hidden in-window launcher host (no second UI is shown; the Amethyst launcher's own
Play button is driven programmatically). Minecraft setup (Microsoft sign-in, Fabric profile, JIT
prompt) is a deliberate sheet from the Play setup card or Help, never opened by Play. Automatic
setup installs/updates the bundled VRMC provider mod (hash-verified) and downloads or imports the
pinned Vivecraft build. The in-VR quick menu adds comfort/recovery controls reachable from the game
menu. Provider fixes: look-down false-JUMP regression and seated double-tap snap turn.
